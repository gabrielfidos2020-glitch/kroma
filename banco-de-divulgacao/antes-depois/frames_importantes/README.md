# Frames-chave

Frames extraídos do vídeo original em resolução nativa, sem alterações de imagem. Os tempos ajudam a encontrar os momentos correspondentes no arquivo de origem.

| Arquivo | Tempo | Uso |
|---|---:|---|
| `01_antes-plano-geral.jpg` | 0,8 s | Quadro geral do antes; base da cena de abertura. |
| `02_antes-hold.jpg` | 1,9 s | Sustentação antes do corte para preto. |
| `03_inicio-assinatura-preto.jpg` | 2,3 s | Início da assinatura sobre fundo preto; usar só como referência de timing. |
| `04_fim-pulso-logo.jpg` | 4,8 s | Final do pulso da marca; não regenerar a logo. |
| `05_revelacao-depois.jpg` | 5,4 s | Revelação após o beat. |
| `06_depois-plano-geral.jpg` | 6,8 s | Quadro geral do resultado personalizado. |
| `07_detalhe-carenagem.jpg` | 7,6 s | Close do farol, carenagem, grafismo e roda. |
| `08_detalhe-final.jpg` | 9,1 s | Final do movimento de detalhe. |

O material de origem é conceitual. Para um trabalho real, mantenha os frames apenas como referência de enquadramento e use fotos reais para a aparência do veículo e acabamento.
