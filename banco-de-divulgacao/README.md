# Banco de divulgação KROMA

Materiais de referência e pacotes de produção para vídeos de divulgação. Preserve os vídeos originais; processe cópias silenciosas e frames em subpastas do projeto correspondente.

## Estrutura

- `antes-depois/`: vídeo antes/depois, cópia silenciosa, frames-chave e prompts.
- `catalogo/produtos/`: fotos reais dos produtos/veículos e variantes aprovadas.
- `catalogo/texturas/`: macros de pintura, adesivo, acabamento e material aprovados.

Use fotos reais para travar produto e acabamento. Referências de vídeo orientam movimento e composição. Não misture concept art com fotos reais em uma produção de cliente.

A pasta referencias/ contém cinco referências processadas, cada uma com cópia silenciosa, frames e prompt próprio.
